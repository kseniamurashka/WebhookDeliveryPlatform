# Модель данных

```text
Project
├── Endpoint
│   ├── Subscription
│   └── Delivery
└── Event
    └── Delivery
        └── DeliveryAttempt
```

Все первичные ключи — UUID, даты хранятся с часовым поясом.

| Таблица | Назначение |
|---|---|
| `projects` | логическая область клиента |
| `endpoints` | URL, секрет подписи и признак активности получателя |
| `subscriptions` | типы событий, интересующие endpoint; пара endpoint/type уникальна |
| `events` | тип, JSONB payload и необязательный ключ идемпотентности |
| `deliveries` | состояние доставки конкретного события на конкретный endpoint |
| `delivery_attempts` | HTTP-код, фрагмент ответа, ошибка и длительность попытки |

Ограничение `uq_event_project_idempotency_key` обеспечивает уникальность непустого `Idempotency-Key` внутри проекта. Индексы на внешних ключах, типе события и подписках ускоряют основной маршрут публикации.
